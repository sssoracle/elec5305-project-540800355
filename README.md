# elec5305-project-540800355
ELEC5305 Project - Power Quality Disturbance Detection and Classification Using Time-Frequency Signal Analysis
This project develops a signal-processing-based system for detecting and classifying common power quality disturbances.
The investigated disturbances include:

- Normal voltage
- Voltage sag
- Voltage swell
- Voltage interruption
- Harmonic distortion
- Transient disturbance

The project investigates several signal processing methods including:

- Fast Fourier Transform (FFT)
- Short-Time Fourier Transform (STFT)
- Discrete Wavelet Transform (DWT)

Machine learning classifiers such as Support Vector Machine (SVM) and Random Forest will be used for power quality disturbance classification.
